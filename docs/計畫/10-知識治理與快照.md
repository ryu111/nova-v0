# 知識治理與快照 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 【推論】建立跨 Work 的知識治理權威：執行者只能提案，唯一 admission writer 決定 ACTIVE／過期／撤銷／取代；Work 只綁 immutable KnowledgeSnapshot，來源失效會沿完整衍生圖傳播而不改寫歷史。

**Architecture:** 【推論】KnowledgeAssertion 的內容 bytes 在 CAS、provenance/derivation 與 lifecycle events 在權威 state store、查詢 index 只是可重建 projection。Knowledge Authority 先依來源、範圍、TTL、admission rule 建立 assertion revision，再將同一次 deterministic resolution 固化成 snapshot。`ADVISORY_CONSTRAINT` 是 assertion profile，與一般知識共用同一支 admission/revocation 筆；它的 ConstraintSpec parsing、scope packing與 context injection 留給 plan 12，避免共用 parser取得知識寫權。

**Tech Stack:** 【推論】CPython 3.14.7、MachineSpec、CAS、SQLite recursive CTE/adjacency index、canonical JSON、fake clock、ClaimSpec runner。

**Spec:** 【查證】本檔「子系統規格」，以及[第二輪知識權威裁決](../sol-新局-第二輪.md#1-q1這個對應缺一面知識治理)、[第四輪告知型約束歸屬](../sol-新局-第四輪.md#12-跨工作的告知型約束確實歸知識不是方便塞法)。

## Global Constraints

- 【推論】Assertion status 固定 `PROPOSED|ACTIVE|REVIEW_REQUIRED|EXPIRED|REVOKED|SUPERSEDED|REJECTED`；內容 revision immutable，狀態不寫回 source bytes。
- 【推論】只有 Knowledge Authority 可進 `ACTIVE` 或撤銷/取代；agent、Work、Pursuit、health observer、HTTP/CLI caller 都只能 `PROPOSED`。
- 【推論】來源不是 URL string；至少有 source entity、generation activity、responsible agent、derivation edges、revision/invalidation evidence refs。
- 【推論】預設 TTL 90 天；可縮短，延長必須新 revision 重跑 admission。沒有永不過期值。
- 【推論】未 ACTIVE 的 assertion 永遠不進 snapshot；snapshot digest 在時間推進、TTL 到期或 index rebuild 後解析相同 revision set。
- 【推論】撤銷保存歷史使用痕跡；新 Work 取不到 revoked assertion，在途 Work 收到 `KNOWLEDGE_REVOKED` 並按釘版 risk policy 顯式 rebase/taint/cancel。
- 【推論】知識不能直接改判準、加預算或產生外部 effect intent；只能透過窄 proposal/snapshot contract被其他權威採用。

## 子系統規格

【推論】`KnowledgeAssertion` 必填 `assertion_id/revision/profile/body_ref/scope/source_evidence_refs/derived_from/proposed_by/admission_rule_ref/valid_from/expires_at/supersedes`；`profile` v1 固定 `GENERAL|ADVISORY_CONSTRAINT`。

【推論】`KnowledgeSnapshot` 固定包含 ordered `(assertion_id, revision, digest)`、`resolved_at`、authority event cursor、query/input facts digest、query policy digest、backend fingerprint 與 serialization-policy digest。相同 authority event prefix、query facts、policy revision、clock instant 與 backend fingerprint 必須解析出同一 snapshot digest；把一次結果存下來只能證明 load 可重播，不能替代 resolve 的決定性。

【推論】v1 query policy 固定六步，沒有 ranked retrieval：①在輸入 event cursor fold exact authority state；②以 typed scope 做 exact filter；③驗證 `ACTIVE`、TTL 與 profile；④沿 provenance DAG 取 deterministic closure（符合者加所有 ACTIVE ancestors；失效 ancestor 只保留 evidence ref，不注入內容）；⑤stable topological sort，ancestor 先於 descendant，同一 topology layer 依 scope 由廣到窄，再以 `(assertion_id, revision, digest)` tie-break；⑥把全部 eligible assertion canonicalize 成 context 與 snapshot，不做 top-k、entity extraction、摘要樹或語義裁剪。

【推論】知識 context hard budget 為 `min(32_768 個 backend-measured input tokens, backend usable context 扣除 system/tool/output 等 mandatory reserves 後的 25%)`。全部 eligible bytes 放不下就回 typed `KNOWLEDGE_CONTEXT_OVERFLOW`；不得截尾、摘要、改用相似度，也不得把成功包裝成「部分知識」。

【推論】KV／prompt cache 只能加速 exact payload：cache key 至少含 snapshot digest、backend/model exact fingerprint 與 serialization-policy digest；hit/miss 送出的 canonical bytes 必須逐 byte 相同，cache 不得選候選、改順序或摘要。

【推論】來源撤銷以 transitive closure 找所有 descendant；每個 descendant 至少進 `REVIEW_REQUIRED`，只有 admission rule 證明仍有足夠獨立來源才可用 successor revision 恢復 ACTIVE，同一 revision 不原地洗白。

## Plan Exit Gate

- 【推論】untrusted caller 永遠只能 PROPOSED；active/revoke/supersede 只有 Knowledge Authority command。
- 【推論】provenance 是 typed graph且 cycle-free，不是 URL 欄；來源撤銷完整傳遞到所有 descendants。
- 【推論】snapshot 只含當下 ACTIVE revisions，之後 clock/index/restart 不改 snapshot digest。
- 【推論】index 可整個刪除重建，不掌握 status truth。
- 【推論】v1 resolution 是 exact scope→ACTIVE/TTL/profile→provenance closure→stable topo→full eligible context；沒有向量、GraphRAG entity extraction、summary tree或 ranked top-k。
- 【推論】context 放不下只回 `KNOWLEDGE_CONTEXT_OVERFLOW`；cache hit/miss canonical bytes相同。
- 【推論】retrieval 只能在 30-day/1,000-dispatch trigger 後以 `RetrievalSelectionWork` 提案，並通過 500-query五項 gate；不能自動降級。
- 【推論】Knowledge Authority 沒有直接寫 criterion/budget/effect 的 import 或 port。
