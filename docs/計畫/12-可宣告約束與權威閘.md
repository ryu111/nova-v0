# 可宣告約束與權威閘 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 【推論】把跨工作重用的「提醒」與不可違反的「邊界」做成同一封閉宣告語言的兩種強度，卻不創造中央萬能權威：ADVISORY 由知識治理並可驗送達，ENFORCED 由被限制操作的既有權威擁有並在不可繞過的 system gate 執法。

**Architecture:** 【推論】neutral `nova/約束/` 只載入、驗 scope、編 immutable plan，沒有 ACTIVE 寫口。ADVISORY ConstraintSpec 映射成 `KnowledgeAssertion.profile=ADVISORY_CONSTRAINT`，Knowledge Authority 產生 ordered ContextPlan；Execution assembler計量並生成 InvocationEnvelope。ENFORCED ConstraintSpec 的 owner 必須與 source path/lifecycle/gate 一致，各權威在自己的 decision/I/O boundary套 plan；Criterion Authority只以 ClaimSpec證明 gate，不取得規則寫權。

**Tech Stack:** 【推論】CPython 3.14.7、JSON Schema 2020-12、typed Predicate AST、MachineSpec/FlowSpec、CAS、SQLite authority ledgers、ClaimSpec 0.2.0、fake clock/context meter/backend contract matrix。

**Spec:** 【查證】本檔「子系統規格」，以及[第四輪 ConstraintSpec、上下文與治理完整定案](../sol-新局-第四輪.md)、[第五輪工具鏈／Guard／額度修正](../sol-新局-第五輪.md)。

## Global Constraints

- 【推論】ADVISORY 只能保證 exact bytes delivery/omission disclosure，永遠不得列入行為 invariant、guarantee 或 accepted verdict。
- 【推論】ENFORCED 規則歸 Execution/Pursuit/Work/Criterion/Resource/Effect/Knowledge 之一；gate 是 PEP，不是規則 owner。
- 【推論】ConstraintSpec source不帶 ACTIVE；bootstrap bytes在 owner-local `規格/`，runtime bytes進 CAS，狀態在 owner ledger。
- 【推論】每條必有 semantic id、explicit scope、statement/reason、proposal/evidence refs、predeclared direct-red control、review/expiry；寫不出固定負控就不得 ACTIVE。
- 【推論】scope 四維 `work_types/backend_ids/criterion_refs/operation_ids` 全部必填 `ALL|ANY_OF(nonempty)`；不接受 regex、Python predicate、隱含「其餘全部」。
- 【推論】review最晚 90 天、expiry最晚 180 天，沒有 auto-renew。到期 ADVISORY停止注入；ENFORCED semantic slot fail closed到有 successor或有證據 RETIRED。
- 【推論】required mediation/isolation capability不滿足時 `UNSUPPORTED_CONSTRAINT_ENFORCEMENT`；不得改當 ADVISORY、skip 或只靠 backend native hook。
- 【推論】同一 Execution scope最多 16 條 ACTIVE ADVISORY，statement canonical UTF-8最多 1,024 bytes，semantic id最多64 ASCII bytes。

## 子系統規格

【推論】`ConstraintSpec 1.0.0` top-level固定 `$schema,constraint_version,constraint_id,revision,supersedes,strength,owner,lifecycle_machine_ref,scope,statement_ref,reason_ref,proposal_event_ref,evidence_refs,claim_binding,valid_from,review_at,expires_at,advisory,enforcement`，所有 object `additionalProperties=false`。

【推論】`AdvisoryPolicy`固定 `text_ref,delivery_requirement(REQUIRED_FOR_DISPATCH|BEST_EFFORT),persistence(INVOCATION_START|REASSERT_EACH_TURN),priority(0..100)`；`EnforcementPolicy`固定 `gate_ref,gate_catalog,operation_ids,predicate,on_violation,reason_code,required_capabilities,enforcement_claim_ref,defense_in_depth`。

【推論】Context budget：`H=max(512,ceil(.05*C))`，`A=max(0,min(4096,floor(.10*C),C-O-U-H-M))`。REQUIRED全放或不 dispatch；BEST_EFFORT排序 `(priority DESC, scope-specificity DESC, reviewed_at DESC, constraint_id ASC)` 後整條 first-fit，不截斷/摘要。
