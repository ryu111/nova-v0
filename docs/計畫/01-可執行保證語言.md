# 可執行保證語言 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 【推論】建立最小信任根：一份 ClaimSpec 可確定性編成外部 TestPlan，對 actual／正控接受，對事前固定錯誤 subject 產生指定 direct red，且 harness fault 永不冒充候選失敗。

**Architecture:** 【推論】ClaimSpec source 與 mutable verdict 分離；compiler 只接受封閉 primitive catalog 與 typed predicate AST。外部 pytest adapter 把 actual、positive sensitivity、negative sensitivity 各註冊成獨立 test id，EvidenceRecord 保存 direct result；production subject 只由 BindingManifest 綁定。

**Tech Stack:** 【推論】CPython 3.14.7、uv、JSON Schema 2020-12、pytest 9.1.1、Hypothesis、xdist、mutmut 3.7.0、dataclasses／enum、SHA-256 canonical JSON。

**Spec:** 【查證】本檔「子系統規格」，以及[第二輪 ClaimSpec](../sol-新局-第二輪.md#5-q5第一份具體檔案與-claimspec-v0)、[第五輪工具鏈實測](../sol-新局-第五輪.md#4-cpython-314不是看起來支援是真的跑過)、[控制端複驗](../控制端審查.md#工具鏈我的一手複驗不是採信它的宣稱)。

## Global Constraints

- 【推論】Python 固定 3.14.7；所有 schema object `additionalProperties=false`；semantic ids 用 ASCII。
- 【實測】pytest 同時 discover `測_*.py/test_*.py`、`測試_*/test_*`、`測_*/Test*`，`pythonpath=["."]`。
- 【實測】mutmut 設 `source_paths`、list 型別 `tests_dir`、list 型別 `also_copy`；不得以 mutation kill rate 驗收。
- 【推論】actual／positive 必須 `ACCEPT`；negative 必須 direct `CLAIM_REJECTED` 且 failed predicate ids 恰等於 `must_fail_exactly`。
- 【推論】`UNBOUND_SUBJECT`、`UNSUPPORTED_ISOLATION`、`HARNESS_ERROR`、`HARNESS_LIMIT` 是獨立結果，不得被 negative control 當成功。

## 子系統規格

【推論】輸入是 immutable ClaimSpec bytes、PrimitiveCatalog digest、BindingManifest digest、IsolationOffer digest；輸出是 immutable TestPlan 與 typed CaseResult。statement 只供人讀，沒有判定權。

【推論】ClaimSpec 0.2.0 top-level 固定包含 `$schema`、`claimspec_version`、`claim_id`、`revision`、`supersedes`、`statement`、`sources`、`primitive_catalog`、`subject`、`parameters`、`setup`、`stimulus`、`observations`、`judge`、`controls`、`run_limits`、`isolation`、`effect_delivery`、`evidence`、`feedback`、`cleanup`；`effect_delivery` 依是否使用外部效果原語而必須是閉合契約或 `null`，檔案內沒有 ACTIVE／PASS／admitted_by。

【推論】designated mutation 是 `NegativeControl` 或 `MutationControlRef` 在 admission 前固定的 faulty subject／semantic anchor；mutmut 全掃只產生 diagnostic EvidenceRecord，不產生 acceptance percentage。

```python
@dataclass(frozen=True, slots=True)
class SemanticId:
    value: str

    @classmethod
    def parse(cls, raw: str) -> "SemanticId":
        if re.fullmatch(r"[a-z][a-z0-9]*(?:[.-][a-z0-9]+)*", raw) is None:
            raise InvalidSemanticId(raw)
        return cls(raw)

def canonical_json_bytes(value: object) -> bytes:
    return json.dumps(value, ensure_ascii=False, sort_keys=True, separators=(",", ":"), allow_nan=False).encode("utf-8")
```

```python
def run_with_wall_limit(argv: tuple[str, ...], wall_ms: int, grace_ms: int) -> ExecutionResult:
    process = subprocess.Popen(argv, start_new_session=True, close_fds=True)
    try:
        process.wait(timeout=wall_ms / 1000)
        return ExecutionResult.from_returncode(process.returncode)
    except subprocess.TimeoutExpired:
        os.killpg(process.pid, signal.SIGKILL)
        process.wait(timeout=grace_ms / 1000)
        return ExecutionResult.terminal("TIMED_OUT")
```
