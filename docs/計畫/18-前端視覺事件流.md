# 前端視覺事件流 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 【推論】交付「像流程圖一樣看到現在走到哪一格」的visual-log UI：只靠GraphBundle與事件流純函式重建三層tokens、系統健康、per-bucket額度、constraint context與低頻控制結果，永遠不向領域發額外查詢。

**Architecture:** 【推論】browser先按digest載入GraphBundle，再用event catch-up+SSE live feed驅動pure reducer；Web Components只渲染reducer state。靜態node/edge來自MachineSpec/FlowSpec生成的GraphIR/SVG，runtime events只放entity tokens/overlays。command client只送plan 13 typed commands；view不持有allocation/update/constraint admission決策。

**Tech Stack:** 【推論】TypeScript strict、Vite、Vitest、fast-check property tests、AJV JSON Schema validation、native Web Components、SVG、EventSource、locked npm dependencies。

**Spec:** 【查證】本檔「子系統規格」，以及[前端控制需求](../需求-前端控制.md)、[第三輪view/model與前端定案](../sol-新局-第三輪.md)、[第五輪per-bucket額度誠實語義](../sol-新局-第五輪.md#1-額度接受五種情況但狀態的主詞必須改對)。

## Global Constraints

- 【推論】model不為view讓步；event field必須由domain invariant證成，UI缺欄時改view/reducer，不回頭加domain query或view-only event。
- 【推論】reducer固定`(GraphBundle, PriorViewState, DomainEventEnvelope, TrustedUiNow) -> NextViewState|TypedFoldError`，無I/O、無global clock、無HTTP。
- 【推論】UI永不讀authority DB/transaction；只接independent tail store的public event stream與digest-onlyGraphBundle。
- 【推論】event duplicate按seq+digest冪等，gap/out-of-order停在typed degraded state並reconnect catch-up，不猜補。
- 【推論】SSE transport heartbeat只帶cursor，不更新component health；domain component heartbeat每10秒，UI本地now超過30秒標STALE。
- 【推論】quota逐bucket顯示五證據態、metric kind、observed/reset time、source、aggregate eligibility/local budget/in-flight reservations；rolled不得畫full，NOT_APPLICABLE不得畫∞。
- 【推論】ADVISORY omitted/included及reason必須可見，且文字明示delivery不等於behavior guarantee。
- 【推論】source可中文，wire/state/reason/semantic ids ASCII；zh-TW dictionary只改顯示，不改GraphBundle/event digests。

## 子系統規格

【推論】ViewState固定分區`stream,graph,entities,system,backends,constraints,commands`。`entities`以machine id/state id/entity id/parent id存tokens，不硬編Work/Pursuit/Execution enum；unknown admitted semantic id顯示原id並記translation-missing warning。

【推論】quota `BucketView`保留evidence union，不壓成remaining number；aggregate eligibility是Resource Authority event的fold，不由前端重算policy。

【推論】低頻controls固定三組：allocation basis points、request pinned backend update（只在manifest supported）、local explicit constraint review/approval。form只做wire/schema預驗，server rejection仍是權威結果並進visual log。
