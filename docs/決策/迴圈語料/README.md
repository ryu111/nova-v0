## 讀的時候要記住三件事

1. **這些是二手資料。** 每一個 DOI、每一個 grep 命中數都被重跑驗證過才進帳本——
   實測抓到過一個**編造的 DOI**（`10.1111/j.1467-985X.1996.tb00086.x`，Crossref 回 404）。
   語料裡沒被帳本引用的部分，**沒有經過驗證**。
2. **裁決會推翻語料。** 例如語料裡有幾處把私人 taxonomy 當業界標準；
   十二項降級清單就是修正它們的結果。以帳本為準。
3. **不要拿語料當接受權。** 唯一的產品接受權在 ClaimSpec 閘。
